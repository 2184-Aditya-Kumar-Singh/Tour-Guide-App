# Tour-Guide-App

City Tour Guide Application
A comprehensive tour guide application that helps users explore cities through their local cuisine and tourist attractions. Users can discover detailed information about various locations and traditional foods, complete with visual representations.
Features
City Selection

Interactive city selection interface
Support for multiple cities with expandable database
Easy navigation between different cities

Exploration Categories

Two main categories for exploration:

Local Cuisine
Tourist Attractions



Food Discovery

Comprehensive list of local dishes
Detailed information for each food item including:

Description and history
Common ingredients
Where to find it
Price range
Seasonal availability (if applicable)
Images of the dishes



Tourist Attractions

Complete list of notable locations
Detailed information for each attraction including:

Historical significance
Opening hours
Entry fees
Best time to visit
Location and directions
Visitor tips
Representative images



User Interface

Clean and intuitive design
Easy navigation between different sections
Visual representations for all items
Search and filter capabilities
Responsive design for all device types

Technology Used
Java
Android Studio
